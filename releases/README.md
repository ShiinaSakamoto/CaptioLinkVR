# リリースノート

バージョンごとの更新内容を `vX.Y.Z.md` に書きます。GitHub Release の本文になり、アプリのアップデート確認ダイアログにも表示されます。

## 手順

1. バージョンを上げる（ノート下書きも作成されます）:

```bash
npm run bump-version -- 0.2.6
```

下書きの箇条書きは次のルールです（件数上限なし）。

- 作業ブランチが `main` より進んでいる → **`origin/main`（または `main`）以降〜今の HEAD** のコミット（これから main へマージする分）
- すでに main へマージ済み → **直前の main マージで取り込まれたコミット**（マージ直後に bump してリリースする想定）
- `Merge ...` 自体のメッセージは除外し、実コミットの件名だけを列挙します

既存の `releases/vX.Y.Z.md` がある場合は上書きしません。下書きを作り直すときはそのファイルを消してから、同じバージョンでもう一度 `npm run bump-version -- X.Y.Z` を実行してください（バージョンが既に同じでも、md が無ければ作成します）。

2. `releases/v0.2.6.md` を編集する（コミット要約の下書きを人間向けの文言に整える）
3. 変更を commit して `main` へ push する
4. Release ワークフローがノートファイルを Release body として公開する

ノートファイルが無いとリリースジョブは失敗します。
