SteamVR オーバーレイ向けの字幕表示ツールです。<br>
VRChat ワールドなどで使える字幕プリセットを選び、HMD 上に字幕を表示できます。

<br>

## ✨ できること
- HMD上に字幕をオーバーレイ表示
- 使用者のみに字幕を表示（周囲の演出には影響なし）
- 字幕ファイルの再生（同梱プリセット、またはsrt/assaファイルに対応／カウントダウン形式で再生開始）
- 表示のカスタマイズ（文字サイズ・位置・色など）

<br>

## 💻 動作環境
- Windows
- SteamVR

<br>

## 🚀 使い方（概要）
1. SteamVR と本ツールを起動する（VRChat を PCVR で起動していれば、SteamVR は自動で起動していることが多いです）
2. 「字幕テスト送信」で、HMD 上に字幕が問題なく表示されるか確認する
3. ソフト内で字幕プリセットを選び、対応する VRChat ワールドへ移動する
4. 字幕を再生し、カウントダウンに合わせて演出を手動起動する
5. HMD 内のオーバーレイで字幕を確認する

詳しい手順は、各プリセットの説明文を参照してください。

<br>

## ⚠️ 注意
本ツールは、基本的に**一人用**です。
**字幕を再生する本人が、ワールド側のギミックも起動する**使い方を想定しています。

字幕の表示・再生開始はご自身の PC 上でのみ行われ、周囲のプレイヤーには共有されません。ワールド側の演出開始も各プレイヤーのローカル再生に依存するため、通信遅延などにより他の人とタイミングがずれることがあります。同じインスタンスで複数人が同時に字幕を使う用途には向いていません。
