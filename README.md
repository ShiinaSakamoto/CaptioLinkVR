SteamVR オーバーレイ向けの字幕表示ツールです。<br>
VRChat ワールドなどで使える字幕プリセットを選び、HMD 上に字幕を表示できます。

<br>

## ✨ できること
- HMD上に字幕をオーバーレイ表示
- 使用者のみに字幕を表示（周囲の演出には影響なし）
- 字幕ファイルの再生（同梱プリセット、またはsrt/assaファイルに対応／カウントダウン形式で再生開始）
- 表示のカスタマイズ（文字サイズ・位置・色など）

<br>

## 💻 動作環境
- Windows
- SteamVR

<br>

## 🚀 使い方（概要）
1. SteamVR と本ツールを起動する
2. プリセットを選び、VRChatワールドへ移動する
3. 字幕を再生し、カウントダウンに合わせて演出を手動起動する
4. HMD 内のオーバーレイで字幕を確認する

各演出での詳しい字幕表示の使い方は各プリセット字幕の説明文を見てください。
プリセット字幕はソフト内から選択できます。<br>

## <a id="字幕プロジェクトのポリシー">📌 字幕プロジェクトのポリシー</a>
- 使用音楽や台詞に著作権上の問題がないこと
  - ワールド制作者が著作者、または著作者の許可がある場合はOK
- ワールドが常設であること
  - 字幕起こしや、テストを十分な回数行える場合はOK
- 再生ギミックはユーザー操作や定時で発動すること
